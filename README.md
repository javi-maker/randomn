# The Charade (working title)

An epic novella about a man who wakes up inside a game he never agreed to play — a dark, complex, sadistic charade whose rules everyone else seems to half-know. The board is populated by demons, witches, ex-girlfriends, an ex-girlfriend's mother, siblings, family, friends, and neighbors. His only steady companion is Fable: a voice that takes form, knows the shape of stories, and helps him decipher the design as he moves through it.

## Repository layout

- `manuscript/` — the novella itself, one file per chapter.
- `story-bible/` — the canon: characters, timeline, dimensions, rules of the game, and the protagonist's working hypotheses.

## How we work

1. The author's head-canon is the source of truth. The story bible files contain structured slots — fill them in, in any order, in fragments or full paragraphs.
2. Fable (the collaborating model) drafts and revises prose against the bible, never contradicting confirmed canon. Anything Fable invents before canon exists is marked **provisional** and can be overwritten without ceremony.
3. Each chapter lives in its own file so revisions stay reviewable.
