# Hypotheses

The protagonist's working theories about the game, tracked like a detective's murder board. Each hypothesis gets evidence for, evidence against, and status. The novella's engine is the rise and fall of these — the reader believes each one just before it breaks.

Format:

> **H#. Statement** — Status: `live | wounded | dead | confirmed`
> Evidence for: … Evidence against: … Which chapter tests it: …
